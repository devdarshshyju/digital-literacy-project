# digital-literacy-project
This Digital Literacy Project demonstrates essential skills for navigating the online world responsibly. It includes creating a professional digital portfolio, exploring coding and collaboration tools, practicing email etiquette, and understanding cybercrime awareness, helping students build a safe and effective digital presence.
